PIPELINE

What happens to the image

02 / 02
  1. Validation — extension, real file format, size, readability, dimensions.
  2. Quality report — format, bit depth, intensity statistics, contrast, saturation, noise (technical only).
  3. Preprocessing — percentile contrast stretch and 3×3 median filter (no CLAHE, to avoid false edges).
  4. Boundary detection — {% if model.state == 'loaded' %}U-Net retinal layer segmentation{% else %}non-AI heuristic (ILM / RPE) until a trained U-Net is connected{% endif %}.
  5. Measurement — ILM→RPE distance per column, in pixels.
  6. Monitoring — comparison with the astronaut's baseline of the same eye; review alert if the change exceeds ±{{ alert_threshold }}% (demonstration threshold).
