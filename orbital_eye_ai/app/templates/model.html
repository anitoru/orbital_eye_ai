HOW TO CONNECT A TRAINED MODEL
  1. Train in Google Colab with training/colab_train.ipynb (GPU). See training/README.md.
  2. Download retinal_unet.pt from Google Drive and place it in models/ (or set MODEL_PATH). Do not commit it to Git.
  3. Install PyTorch CPU in the app environment: pip install -r requirements-ml.txt.
  4. Restart the app. New uploads will then use the U-Net; older heuristic measurements are not compared with U-Net measurements.
